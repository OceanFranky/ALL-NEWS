# 视频和经验帖的受控维护

## 与竞赛Agent一起执行

2026-10-20起，统一入口 `modules/competition/backend/workflow.ts` 在每次真实竞赛获取结束时执行资源阶段：正常生成候选、详情未变化、材料采集失败或预算停止都会执行。资源失败只记录报告，保留原详情结果和错误。测试注入工具默认不联网，需显式注入资源阶段。

处理顺序：本次竞赛已入库材料中的真实资源链接（同源优先）→ 当前竞赛已启用且到期的额外发现页 → 当前竞赛已有已发布资源的到期复查。所有请求共用本轮上限，材料页不重复下载；不扫描其他竞赛，不调用额外模型。材料链接来自数据库读回，未保存的内存链接不能成为依据。实际出现在材料中的跨站视频／经验链接可以抓取为候选，不继承官方身份；额外发现页仍只跟进同源链接。

后台新增「竞赛Agent运行时接入资源」，`competitionAgentEnabled` 默认true（旧配置读取时补默认值），可独立关闭。它不受「开启定时维护」控制；额外发现来源仍初始逐项关闭，关键词也用于筛选竞赛材料链接。每次均检查资源阶段，URL去重后不重复创建草稿；到期规则用于额外来源和既有资源复查。`maxCandidates=0` 可停新候选发现，`maxChecks=0` 可停已有资源复查。总开关 `COLLECT_ENABLED` 仍必须为true。

竞赛CLI原命令无须改变，例如：

```powershell
node --env-file=.env modules/competition/scripts/ingest.ts --id competition-001 --auto
```

该命令含原竞赛模型调用，只应在模型配置齐备且本次费用已授权时运行。资源阶段本身不调用模型。当前本机缺真实竞赛模型配置，本次仅用隔离数据库与本地HTTP夹具验证，不启动真实31项付费获取。

队列入口 `competition.ingest` 也调用同一函数。新闻常驻worker保持原先的竞赛隔离；需要消费已有竞赛／资源任务时，单独运行：

```powershell
node --env-file=.env modules/competition/scripts/worker.ts
```

专用worker只消费两条队列，不启动新闻采集或自动排31项任务，不注册定时任务。已排队竞赛任务仍受原采集、模型和预算检查。单次CLI不需启动此worker。

竞赛报告的 `report.resources` 保存状态、维护任务ID、请求数、新草稿数与重复数；维护报告的 `plan.competition` 反向保存竞赛任务ID、名单及赛道范围，后台最近20条报告可查看。已有其他维护任务时本次明确记录skipped，不并发另开。管理员可在维护页停止资源阶段，当前请求结束后停止。

自动接入的终点是待审核资源库。人工确认实际视频、经验内容、身份、范围和年份后，在原资源后台审核发布，R2详情页按既有HTTP接口显示；未知日期保持未知，不用抓取时间冒充新内容。没有真实可读链接时明确报告缺口，不保证每次或每项都发现资源。

## 先使用后台

1. 完成数据库迁移，启动API和Web。在「经验帖与教学视频」点击「自动维护」，地址 `/admin/resources/maintenance`。
2. 来源预填既有31项竞赛发现种子。种子并不代表官方身份已核实，初始逐项关闭。核对网址和赛道后启用；可将网址改为已确认的官方培训、教学视频、优秀作品或备赛经验栏目。每项最多4个发现页。
3. 保存配置及说明。默认每个对象复查间隔1天，每轮最多5个来源页、20条已有资源、10条新草稿、40次请求。硬上限分别10／50／20／60；设来源或已有资源数量为0可以只做另一类维护。频率可改为7天。
4. 点击「预览下一次计划」。预览只读数据库，不联网、不写运行记录。保存配置后才能重新预览和手动运行。
5. 「立即运行一次」只排队，需要上面的竞赛／资源专用worker运行和 `COLLECT_ENABLED=true`。排队／执行中的任务可以停止；当前请求结束后停止后续工作。定时开关只控制未来定时任务，不取消已排队或手动任务。全部操作只对管理员开放，写接口验证CSRF并保存审计记录。
6. 运行报告中的新草稿可直接进入原资源编辑器。人工核对竞赛、赛道、年份、内容质量、作者、官方身份和视频实际播放情况后，再审核发布。

## 独立命令

在项目根目录执行。独立命令只运行资源维护，不启动网站其他采集或模型worker。

```powershell
node --env-file=.env scripts/migrate.ts
# 默认只预览；不联网、不写入
node --env-file=.env modules/learning-resources/scripts/maintain.ts
# 显式授权本进程联网并执行一次，不修改.env
node --env-file=.env modules/learning-resources/scripts/maintain.ts --run --allow-network
```

命令的实际执行同样保存运行记录、审计与草稿，仍受后台已保存的请求上限限制。「立即运行一次」与独立命令在定时开关关闭时也可手动执行；同一数据库只允许一项排队／执行中的维护任务。

## 定时运行

模块提供 `resources.maintain` 调度声明，计划为北京时间03:40每日检查。只有部署的调度器安装了该模块并注册schedule时才会触发，且需后台「开启定时维护」和运行环境 `COLLECT_ENABLED=true` 同时满足。当前新闻worker保持原隔离，专用worker只消费队列，不注册此调度；仅勾选后台定时开关不会启动定时器。本次需求使用竞赛Agent的单次生命周期触发资源阶段，无需额外定时器。调模型不是独立资源维护的前置条件，本次不修改 `.env` 或启动常驻worker。

间隔按每个来源页／资源上次检查时间计算；设置7天表示同一对象7天后才复查。未检查的对象每天按轮次上限继续处理，最久未检查的优先。达到总请求上限后，尚未检查的对象保留在下一次到期计划。来源发现先执行，候选和已有资源复查共用请求总额度。实际请求每次最多8秒、1MB，不自动重试、不跟随重定向；重定向在报告中提示管理员核对最终地址。

只执行一轮资源维护可用上述独立命令；消费后台排队任务可用竞赛／资源专用worker。网页打开和计划预览都不触发抓取或模型。

## 维护会做什么

- 来源范围：独立维护只读取管理员启用的发现页，从中跟进同源、标题包含关键词的普通HTML链接；竞赛Agent另接收本次入库材料已实际出现的资源链接，允许其中的跨站页面作为未核验候选。同样排除PDF／压缩包／视频文件，不无限翻页；动态SPA页面可能无法发现内容。
- 候选：抓取页面后检查正文可读性，URL按标准序列化去重，仅去掉已知追踪参数，保留身份参数和SPA路由。已有草稿、人工编辑及撤回记录一律跳过。新资源保存为未核验草稿，不预设官方身份、日期、作者或适用届次；自动分类只是待人工确认的初值。
- 复查：只检查现有已发布、未标记失效的资源。HTTP404／410、风控、登录、短正文、超时分别记录；相对上次可读正文的文字hash有变化时提示复核。只存hash及检查结果，不保存或转载全文。
- 时效提醒：可靠发布日期超过一年时提示核对是否仍适用，不自动删除历史经验。抓取日期不替代发布日期。近期、实用和可播放仍由人工判断。
- 报告：记录配置快照、操作者、请求次数、新草稿和重复数量、逐链接结果及可处理的资源入口。后台展示最近20次运行，数据库保留全部记录。

## 维护不会替代的审核

页面可读不代表内容优质、视频可播放或本届适用。自动维护不自动发布、撤回、修改既有资源，不恢复人工撤回内容，不创建竞赛正式详情；来源身份也不因“出现在种子文件中”或“由官方网页链接”而自动确认。

小红书通用笔记搜索API目前未确认，且公开搜索存在风控，因此本版不接入第三方付费API、不绕过登录或验证码。可在原资源后台人工录入可核实的经验帖。

## 故障处理

- 任务一直等待：检查worker是否运行。可停止排队任务后使用独立命令。
- 运行中停止：等待当前请求结束（单请求最多8秒），后续请求不再发出。已完成的检查／草稿保留。
- worker被强制关闭：队列执行10分钟过期，不自动重跑以避免重复外部请求。超过15分钟无进度后，后台停止按钮可解除失联任务的占用，再预览新任务。报告保留已持久化进度；极端中断可能使最后一条已保存草稿尚未计入报告，新运行仍按URL去重。
- 访问受限、重定向或错误：打开原网址人工检查，必要时修正来源。异常只形成报告，不直接改变公开内容。
- 来源无新草稿：检查是否为可读HTML目录、链接是否同源、标题是否匹配关键词，以及候选是否已存在。报告不把未发现当作“没有优质资源”。

## 管理接口

所有路径前缀 `/api/admin/resources/maintenance`，无公开接口。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /` | 当前配置、总开关状态、最近20次完整报告 |
| `GET /preview` | 下一次到期计划，无联网、无写入 |
| `PUT /` | `expectedVersion`、`reason`、`config`；配置冲突返回409 |
| `POST /run` | 请求体 `{}`，排队运行一次；总开关关闭或已有活动任务返回409 |
| `POST /:id/stop` | 请求体 `{}`，停止或请求停止 |

配置、运行、检查表独立于竞赛数据和公开资源表，迁移0071–0074只新增表和索引，保留已有89条资源及历史。
