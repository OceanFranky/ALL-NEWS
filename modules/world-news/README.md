本目录只保存世界新闻专属内容。不得把六源写入 `industry/sources.json`，不得覆盖现有 AI 提示词、门槛或分类。

`rules.ts` 维护三个分类、独立模型步骤和未校准门槛；`prompts/` 保存详细可执行规则稿（相关性、五轴评分、充分性／结构、中文写作、事件关系／独立复核、综述）。`server.ts` 注册规则和独立分析队列，没有自动采集计划或公开路由。世界模型明确选择 `default`，复用现有服务配置，但不读取 AI 的步骤开关；管理覆盖使用 `sections.world.models.<步骤>`。门槛保持空值，不自动精选。

`tests/` 验证严格板块身份、缺规则不回退、并发提示词、AI 文本与版本兼容、模型选择、升级兼容、数据库关系和材料身份。跨板块同链接测试只在每个文件自己的临时数据库模拟后续切换；发布迁移仍保留旧全局唯一约束，世界材料入口暂不开放。30 条已保存 RSS 材料用于离线重放，不是本轮联网试抓或真实模型验收。

下一批完成任务／召回／读取／回执预算隔离并审查切换，再按后续阶段增加六源配置与本地 RSS／HTML／JSON 读取器素材；共享能力仍留在共享引擎，不复制两套后台。

2D 首批只收紧旧 AI 出口：统一公开条件默认 AI，详情／分享／收藏／事件身份、报告目录与读取、精选同步、统计及站点地图补齐 AI 范围；AI 热度只读取自己的信号，清理不删除世界快照。`tests/publication-isolation.test.ts` 在专用测试库同时保存两板块公开材料，通过 HTTP、RSS、Agent 与本地 MCP 验证不串；不代表世界新闻已可采集或发布。

2D 第二批：`jobs.ts` 的生产／消费载荷必须携带 `sectionId: "world"`，消费再次核对数据库归属，运行记录标为 world。共享 `editorial/section-analyze.ts` 执行相关性 → 充分性／结构 → 两次独立评分 → 中文文案，全部从注册世界规则读取；只用已有 excerpt，不自动抓全文。缺摘要或只有重复标题不调模型，未知／不足不公开，unsupported 原文证据拒绝。

付费调用必须附真实资源身份；`section_budgets` 与原 `budgets` 的限制在同一服务事务锁下检查，world 未配置时暂停，已收到答案可复用。旧 AI 回执身份不变；此表限制请求次数，不等于人民币费用上限。真实小批运行前仍需建立可核对的 5 元上界。当前没有真实模型验收或六源接入完成声明。

第三批正在验证：共享 `events/section-group.ts` 在 world 内召回候选、逐对关系判断及独立复核；同一具体发生共用事实，直接进展为同事件的另一事实，评论仅提及，不生成事实／热度。按板块串行锁防止多 worker 同时新建同一事件；当前不自动合并已有两个事件，人工合并和纠正接口仍待实现。

`/api/v1/world/items`、`items/:id`、`stories`、`stories/:publicId`、`hot` 已注册，统一从 `publication/sections.ts` 读取，只提供摘要和原文链接。非法分类／参数拒绝，跨板块资源 404，撤回后不可读。热点未校准返回 `calibration-required`；这些公开接口不会触发模型。不代表文章已自动发布、来源已实际采集或后台页面完成。
