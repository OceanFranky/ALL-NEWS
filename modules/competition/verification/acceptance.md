# 官网到竞赛数据库验收标准

本验收覆盖全部31项名录的运行与缺口，不能用三条样本替代全范围完成。实施中分阶段记录证据，直到本文件所有要求满足才认定目标完成。

## 本阶段验收口径（2026-10-14使用者澄清）

使用者明确不需要等待24项人工审核。本阶段验收官网到候选数据库的完整执行链路、实际数据和异常记录；不将管理员批准、全字段known或补齐全部宣传图作为交付前提。所有31项仍须纳入报告，未获取项不能删除或记为成功。结构／证据检查不能证明全部字段语义，已知错例应纠正，剩余缺口按状态留库。

`readyForReview`是内部基础校验结果，不是要求使用者审核的任务队列；当前修订是draft或needs_review，不是公开发布数据。此前30项／1项失败的状态已由017官方通知图片恢复：最新31项均有候选，31项schema／引用校验和读回通过，缺失字段仍明确保留。后续信息补齐、人工审核、公开发布与每日生产部署单独跟进。

最新逐项读回证据见[最终快照](2026-10-14-final-ingestion.json)，逐要求验收见[最终报告](2026-10-14-final-ingestion.md)。此前[30项快照](2026-10-14-ingestion-handoff.json)与[交付报告](2026-10-14-ingestion-handoff.md)保留为历史。下方标准中的“逐项”指真实执行、校验与异常覆盖，不新增24项人工批准门槛。

| 要求 | 验收证据 |
| --- | --- |
| 名录输入 | 数据库31项学校级别和原名逐项匹配；多范围级别不丢失 |
| 官网发现 | 每项保存官方身份依据、RSS／列表实际检查及未确认原因；未确认来源不作为可信字段依据 |
| 材料采集 | 可查询实际URL、抓取时间、内容指纹和请求结果；首页、规则、赛段及调整材料按需组合 |
| 内容解析 | HTML、附件及动态页有可回看的文本位置；解析失败有记录；至少实际验证PDF、DOCX及动态读取 |
| LLM提取 | 真实授权模型调用经过共享回执；仅批准字段，输出证据；学校级别由原名单合并 |
| 校验与补查 | 字段范围、届次、日期精度、人数口径、缺失原因、冲突与证据检查的真实失败测试通过 |
| 信息入库 | 材料、任务、字段候选和结果修订实际写入PostgreSQL；独立查询能复核官方字段 |
| 隔离 | 仅竞赛专属表存竞赛业务数据；跨竞赛任务／材料引用被拒绝；AI新闻等业务表未发生修改 |
| 版本与重复 | 重采同材料无重复；新届和延期修订保留旧数据；原URL内容改变可识别 |
| 费用 | 首轮和使用者另授权的第二轮各人民币10元硬上限，分轮保留价格依据、预留额度和用量估计；未结算请求不清零，未知价格不能无界运行 |
| 工程交付 | 类型检查、数据库测试、前端构建与前端测试、启动后smoke、迁移检查和Git差异检查；提交推送竞赛分支 |
