# 学院／专业要求与官方来源

2026-10-17，院系扩展版。目标是逐步覆盖39所历史985院校的学院与专业，优先计算机、软件、人工智能、电子信息等方向。用户确认本轮不追加模型费用。

## 当前可以使用

- 学校→已收录院系→已收录专业／项目精确筛选；院系／专业选项是已发布材料中的范围，不是学校完整名单。专业字段有时对应联合项目或一组专业，尚未拆成完整专业代码目录。
- 同年、同保研／考研路径的校级公告单列为参考，不将学校条件复制成学院要求。招生阶段与批次仍需各自核对。
- 公告卡片可展开申请条件及材料，并直接打开原文。摘要不表示全文要求已穷尽，空白不表示没有门槛。
- 官方细则／汇总、招生专业目录、学院栏目分组展示，保留链接出处。计算机等相关入口优先排列。
- 固定39校／学院的自动扩充已按用户要求停止。上述链接保留供查找；用户可把目标学院公告或栏目提交到“我的来源”，由后台定期跟进。原轮询工具仅保留手动研究用途。
- 具体公告继续进入原有正文／附件、LLM证据提取、公开版本与变更链路。发现链接、尝试读取页面、提取要求和发布公告分别计数；目录链接不会被当成招生机会。

公开验收快照：97条公告、39校；其中12条涉及具体学院／项目，分布9校，包含专项及联合培养，不能当成12个完整学院。已发现38校759个去重入口URL：121个目录、201个细则／汇总、437个学院栏目；一个学院可对应多个URL。首轮尝试读取16校52个学院页面，不等于52个学院要求已提取。

## 尚未完成

尚未全量结构化每校每学院每专业的英语、成绩排名、跨专业、考试科目、招生人数与复试办法。专业目录PDF／交互查询系统本轮主要提供原入口，不能据此声称目录内每一专业已解析。博士单独招生、国际生招生、名单公示不作为本模块硕士机会。

此前自动任务已使固定批次`985-first-20261017`累计保守记账达到4.961002元／5元，剩约0.039元，包含未知失败的预留，并非已核对的平台账单。本轮来源发现和学院巡查使用`MODEL_CALLS_ENABLED=false`，没有增加预算或建立新批次。原模型链路继续受同一硬限约束；新增细则只能在既有额度允许时提取，否则保留待处理。

## 公共接口

`GET /api/v1/admissions?school=s004&department=...&programme=...`新增精确筛选（URL编码中文）。返回`departments`、`programmes`、`schoolRules`及`directory`。院系／专业选项结合当前其他筛选计算；未选学校时不提供选项。`directory`只在正式数据且已选学校时返回。

`directory`包含`schoolId,url,title,kind,parentUrl,checkedAt`，`kind`为`department/catalogue/rules-index`。`checkedAt`指在来源页面发现该链接的时间，不表示目标页全文已整理。

手动补源巡查可用`node --env-file=<私有配置> scripts/admission-directory.ts [s004 ...]`；需开启升学采集开关，该脚本本身不调用模型。数据库新增0077、0078迁移，仅增加派生来源表与巡查时间，不修改已有公告身份。
