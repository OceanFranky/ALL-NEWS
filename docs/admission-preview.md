# 保研／考研自动更新与服务器预览

2026-10-17，分支 `codex/admission`。当前围绕用户提交的官网链接自动读取、模型提取、证据检查与公开展示。保留前期97条公告、39校和学院入口记录；停止按固定39校名单自动扩大采集。逐校范围和缺口见[覆盖记录](admission-985-coverage.md)，不代表所有院系／专业齐全。

## 使用入口

- [我的来源](http://1.92.71.135:8080/admissions/sources)：添加官方公告或招生栏目，查看读取状态、已发布结果和恢复链接。本机最多20个来源，无账户同步。公开链接和整理结果共享，移除本机清单不会暂停后台任务。
- `/admin/admissions/imports`：管理员查看最近100个来源、失败原因及累计费用，暂停、恢复或重新排队，沿用登录和CSRF保护。

- [机会看板](http://1.92.71.135:8080/admissions)：保研／考研、关键词、学校、地区、层次、年份、阶段和日期筛选。
- [收录动态与每日简报](http://1.92.71.135:8080/admissions/updates)：首次收录／更新、未来7天截止、历史39校来源检查记录。简报由已发布数据编排，不额外调用模型。
- [院校目录](http://1.92.71.135:8080/admissions/schools)：112所历史211院校／116办学条目，其中985为39所。目录内其他211可由用户提交官方链接，“其他本科”尚未批量录入。
- 公告详情：范围、条件、材料清单、日期精度、机器引用检查、官方正文和附件；浏览器独立收藏、材料勾选及手动导入的日历下载。
- `/admin/admissions`：人工草稿、发布、撤回、版本冲突及审计；公网403，仅服务器本机／SSH隧道管理。

公开页面及接口只展示数据库中已发布的真实公告；体验示例、示例详情、示例收藏及示例日历已移除。旧 `?dataset=demo` 链接统一读取真实公告，不再提供第二套数据。浏览器升级时清理旧示例收藏和对应材料勾选，保留真实收藏；原示例未写入公告库，无需删除业务数据。合成夹具仅存于测试目录，不被运行时代码引用。机器整理记录不能误解成人工逐条审核，没有已核对的经验／视频资源时明确为空。

## 自动流程与费用

用户在“我的来源”提交具体公告或招生栏目，后台按院校目录核对官方域名。独立worker每分钟查用户来源的到期任务，通常每60分钟复查一次；首次栏目有未读候选时隔一分钟继续，每轮最多2份文档、并发2。栏目只读提交页当年及次年招生标题，最多50个候选，不遍历整个官网或分页。读取正文与附件、保存hash快照，再经DeepSeek、字段证据检查和审计发布。未变化跳过模型，最多一次有界纠错，仍不合格则待核对。新的官方延期公告必须明确链接原机会；人工修改／撤回受保护。

模型固定为官方 `deepseek-flash`，API及Key仅在服务器私有配置。累计批次 `985-first-20261017` 总上限5元，不重启重置；保守预留和回执联合记账。达到剩余额度不足以预留下一次请求时，继续采集、模型暂停，不自动增加预算。当前保守记账4.961002元；剩余额度不足的材料保留待处理，以数据库 `admission_allowance` 为准。未知失败保留预留，缓存重用记0元。访问公开页面不会启动模型任务。

兰大校级入口在采集端412，用户浏览器可打开；目前仅管理学院备用公告。山东考研及四川保研目前仅2026历史材料；同济考研、华师保研等也有限定项目范围。扫描附件、失效链接和模型失败保留待处理，详情公开未解析补充附件说明。详细缺口见覆盖表。

## 服务器运行

- Ubuntu24、Node24.21、PostgreSQL16；独立 `allnews_preview` 数据库、专用非root用户 `allnews`。
- 当前 `/opt/all-news/current` 指向 `/opt/all-news/releases/20261017-personal`，迁移至0079。升级前备份 `/opt/all-news/shared/before-personal-20261017.dump`（600）。
- `all-news-api` 回环3101、`all-news-web` 回环3100、Nginx公网8080；`all-news-admission-worker` 只执行升学任务，三个服务均开机启动。API/Web保留关闭的采集／模型安全阀，由专用worker进程单独覆盖；不启用AI／世界的付费工作流。
- 配置 `/opt/all-news/shared/preview.env`（600），共享材料 `/opt/all-news/shared/data`。源码、Git、补丁包和日志不包含Key或SSH密码。
- HTTP预览，后台仅服务器本机／隧道。可用 `ssh -L 8088:127.0.0.1:8080 root@1.92.71.135` 后访问 `http://localhost:8088/admin/admissions`；管理员口令在私有配置的 `ADMIN_PASSWORD`。
- 保留校园网盘目录、数据、数据库及配置。验收时其服务已被停用，80／3001无监听，本轮没有恢复或修改它。初版文档中“仍active／HTTP200”的历史结论不适用于当前状态。

服务文件位于 `deploy/`。检查 `systemctl status all-news-api all-news-web all-news-admission-worker` 和对应journal。更新先备份，在新release安装依赖、迁移、构建及验证，再切换链接。回退时先停止专用worker，切回旧release并重启API/Web；不要删除数据库、审计、共享材料或校园网盘数据。旧版不兼容新增自动处理时，保持worker停止。

## 人工纠错与GitHub交付

## 用户来源版更新（2026-10-17）

新增0079 `admission_imports`，仅存公开URL、学校、来源类型、状态和关联材料ID，不存读者账号。JSON提交只写排队记录，页面读取不会抓取或付费。相同规范URL复用同一来源，不同类型冲突拒绝；全站每小时30个新来源、总500个。拒绝非官方、特殊端口、URL凭据与敏感参数；读取继续使用DNS／重定向防护、体积与时间边界。暂限目录内112所院校的官方域名，不支持任意站点或整站镜像。

新队列`admission.import`替代`admission.refresh`；部署时停worker、先备份业务库，再用pg-boss的deleteQueue清理旧队列及其执行记录，保留公告、来源历史、材料、回执、费用与审计。原39校来源配置和手动研究工具仅供历史追溯／人工操作，不再进入定时调度。cron.admission.schedule仍每分钟触发，内容转为调度已添加来源。回退到faculty版本时先停worker，切回API/Web；保持旧worker停止，避免恢复固定39校采集。新表和用户清单数据保留。

模型沿用原DeepSeek与固定5元硬限，没有新增批次或预算。遇到额度不足、附件失败、扫描件、JS动态栏目或无当年标题时展示待处理／未发现；读取字数与候选数量不等于已提取要求。机器摘要只展示通过原校验的公开版本，撤回记录不会从来源页面泄露。来源恢复链接可保存、分享；本机清单损坏时保留原数据，存储不可用时临时显示结果并提示另存链接。
